# 🤖 NorthHunter AI - סוכן אוטונומי לאיתור והגשת משרות הייטק בצפון

ברוכים הבאים ל-**NorthHunter AI** - סוכן בינה מלאכותית ואוטומציית דפדפן (Playwright) שפותח במיוחד לאיתור משרות הייטק ופיתוח תוכנה ב**אזור הצפון** (חיפה, פארק מת"ם, יקנעם, כרמיאל, קריות, נשר, גליל) והגשת מועמדות אוטומטית / חצי-אוטומטית עם מילוי פרטים וצירוף קורות חיים.

---

## 🌟 יכולות המערכת

1. **איתור משרות ממוקד צפון (Scraping & Aggregation):**
   - סריקת משרות מ-**LinkedIn** עם מסנני מיקום גאוגרפיים ייעודיים לצפון ישראל.
   - תמיכה במערכות גיוס ישירות הפופולריות בהייטק הישראלי: **Comeet**, **Greenhouse**, **Lever**.
   - כיסוי חברות מובילות בפארק מת"ם חיפה, פארק המדע יקנעם, כרמיאל והגליל (Elbit, NVIDIA, Philips, Lumenis, KLA, Sanmina ועוד).
   - אפשרות להוספה ידנית של קישור משרה מכל אתר (לינקדאין, AllJobs, Drushim וכו') בלחיצת כפתור.

2. **ניתוח קורות חיים והתאמה חכמה (AI Match Engine):**
   - העלאת קורות חיים בפורמט PDF וניתוח טקסטואלי אוטומטי (חילוץ שנות ניסיון, טכנולוגיות, מייל, טלפון, קישורים).
   - חישוב **ציון התאמה (Match Score %)** לכל משרה בהתבסס על השוואת דרישות המשרה מול הפרופיל שלך.
   - בונוס התאמה גאוגרפי מיוחד למגורים בצפון – יתרון משמעותי מול מגייסים!

3. **יצירת מכתבי פנייה אישיים (Tailored Cover Letters):**
   - יצירת מכתב פנייה ייחודי לכל משרה וחברה, המדגיש את הניסיון בטכנולוגיות הנדרשות ואת היתרון של מגורים בצפון ללא פקקים.

4. **אוטומציית מילוי טפסים והגשות (Playwright Browser Engine):**
   - **מצב חצי-אוטומטי (מומלץ ובטוח):** המערכת מכינה את הטופס, מציגה תצוגה מקדימה וממתינה לאישורך בלחיצה אחת.
   - **מצב אוטומטי מלא:** הגשה אוטונומית ישירה.
   - מילוי שדות קלט (שם, טלפון, מייל, לינקדאין, שכר, זמינות).
   - צירוף קובץ קו"ח (PDF) לשדות העלאת קבצים.
   - דפדפן גלוי (Headful) שמאפשר לך לראות את הסוכן מקליד וממלא שדות בזמן אמת!

5. **מסוף לוגים ודשבורד בזמן אמת:**
   - ממשק ווב בעיצוב Dark Glassmorphism מודרני בעברית מלאה.
   - תקשורת WebSocket להזרמת פעולות הסוכן בזמן אמת (Live Console).
   - מסייע התחברות מאובטח (Login Assistant) לשמירת סשן הלינקדאין שלך ללא צורך בהזנת סיסמאות בקוד.

## 🚀 הפעלה מהירה

### שיטה 1: הפעלה בלחיצה אחת (Windows)
לחץ לחיצה כפולה על הקובץ:
```cmd
start.bat
```

### שיטה 2: הרצה דרך שורת הפקודה
```bash
python run.py
```
הדפדפן ייפתח אוטומטית בכתובת: **`http://localhost:8000`**

## 💡 טיפים לשימוש יעיל

1. **העלה את קורות החיים שלך:** עבור ללשונית "פרופיל מועמד וקורות חיים", גרור את קובץ ה-PDF שלך. המערכת תעדכן אוטומטית את הטכנולוגיות והניסיון.
2. **חבר את חשבון הלינקדאין:** לחץ על כפתור "חיבור לינקדאין" בראש הדף. ייפתח חלון דפדפן רשמי שבו תוכל להתחבר בבטחה. הסשן יישמר במחשבך.
3. **הגשת מועמדות:** לחץ על `✨ הכן מועמדות ואישור` בכל משרה, קרא את מכתב הפנייה שה-AI הכין עבורך (תוכל גם לערוך אותו), ולחץ `🚀 הגש מועמדות בדפדפן עכשיו`. תוכל לראות במסוף הסוכן ובחלון הדפדפן את מילוי הטופס בשידור חי!
